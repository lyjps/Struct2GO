## Abstract and conclusion language

UAX uses predicted local structural confidence at two stages of sequence–structure prediction. A residue-level prior can bias graph attention when the encoder exposes edge logits, and a separate protein-level gate can combine pooled embeddings or prediction scores after encoding. We evaluated the external gate and the residue prior in controlled comparisons on the BPO, CCO, and MFO branches, with exact amino-acid duplicates removed across evaluation partitions. The external gate produced small changes in Fmax under matched GCN and GAT fusion. The residue prior contributed little in the controlled attention ablation. The score-level gate attached to an adapted TAWFN model with essentially unchanged MFO performance. These results characterize the confidence pathways under the evaluated inputs, model configurations, and splits.

## Methods replacement

### Scope of the attention and fusion modules

The original UAX architecture uses residue confidence during contact-graph attention and protein-level confidence during fusion. The residue operation requires access to the logits of a residue-level graph attention layer and an alignment between graph nodes and the pLDDT vector. The late-fusion operation has a smaller interface. Given protein-level sequence and structure vectors, each vector is projected and layer-normalized in a common space. If c is the mean residue pLDDT divided by 100, the structural weight is a = sigmoid(wc + b). The vector sent to the classifier is a times the projected structural vector plus (1 − a) times the projected sequence vector. The static control learns a global weight using the same model with w fixed effectively at zero by supplying a constant input. A score-level version applies the same weighting rule to predicted GO probabilities from separate encoders. These interfaces require two aligned views and a protein-level confidence value. The late-fusion interface can operate after graph convolution, pooling, or other modality-specific encoding. Transfer to token-level, domain-guided, and geometric encoders remains to be established.

The controlled attention experiment uses a compact GCN input layer, one residual graph attention layer, mean graph pooling, and the same late-fusion classifier in all four conditions. Confidence attention adds log(max((p_i + p_j)/2, 10⁻⁶)) to the post-LeakyReLU attention logit for an edge from i to j, with p_i and p_j expressed on the unit interval. This multiplies the unnormalized attention weight by the confidence prior. Ordinary attention sets the prior to one. The second factor is a learned global fusion weight versus a weight conditioned on mean pLDDT. Within a seed, paired conditions use the same initialization and minibatch order. This design isolates both effects within one graph architecture. The additive log prior is the formulation for the new controlled experiment. The legacy code multiplies signed attention logits by an edge weight before softmax, a different operation whose effect depends on the sign of the logit. Keep the equations for the two versions distinct.

### Structure source and model selection

The preprocessing documentation identifies the AlphaFold Protein Structure Database as the source of the predicted structures. Each archived graph stores one pLDDT value per residue from a single structural record per protein. The late-fusion analysis averages the values over the input graph before pooling, after converting the original 0–100 scale to 0–1. The archive contains graph features, contact edges, and confidence tensors. The exact AlphaFold DB release, source filenames, and model identifiers could not be reconstructed from these processed inputs. Specify the release and accession-to-model mapping if the original download manifest is available. [AlphaFold DB](https://alphafold.ebi.ac.uk/faq)

The present evaluation uses one structure and confidence vector per protein. An independent AlphaFold2 run can generate multiple ranked models. Variability across candidates can affect both the residue confidence values and the set of contacts, with separate consequences for edge attention and the late gate. We did not estimate between-model variance because the archive contains one graph per protein. An ensemble evaluation would align candidates to the same residue sequence, construct contacts and extract pLDDT separately for each candidate, and compare per-model predictions and prediction averaging under a prespecified ranking rule. This would quantify stability in predicted functions without assigning confidence from one model to contacts from another. pLDDT measures confidence in local structure and supplies no direct evidence about the accuracy of long-range contacts or the location of a functional site. [AlphaFold2 implementation and ranking outputs](https://github.com/google-deepmind/alphafold) · [AlphaFold DB confidence documentation](https://alphafold.ebi.ac.uk/faq)

## Results replacement

On the sequence-filtered evaluation partitions, compact DeepGOPlus achieved Fmax of 0.5973, 0.7214, and 0.7734 for BPO, CCO, and MFO, respectively. The corresponding DIAMOND-only values were 0.5521, 0.6396, and 0.7413. This comparison establishes a strong sequence reference on the available splits. The mixture weights were selected using validation data, and the DIAMOND database used only the corresponding training partition. The [results tables](RESULTS.md) also report F1 at the validation-selected threshold, micro AUPR, and seed-level variation.

Across three paired seeds, adding the external confidence gate to the compact GCN changed test Fmax by +0.0024, +0.0017, and +0.0042 on BPO, CCO, and MFO, respectively. With ordinary graph attention, the corresponding changes were +0.0015, +0.0012, and +0.0059. The mean effect of adding the residue-confidence prior ranged from -0.00008 to +0.00004 across the six branch and fusion combinations. These short-budget experiments distinguish a modest change from the late-fusion gate from the much smaller changes due to the residue prior under the matched architecture.

On the adapted TAWFN MFO comparison, the global and confidence-conditioned score blends reached Fmax of 0.6720 and 0.6721. At the validation-selected threshold of 0.37, held-out F1 was 0.6711 and 0.6709. Micro AUPR was 0.7379 for each blend to four decimal places. The confidence-conditioned gate had a fitted slope of −0.7585 on unit-scale mean pLDDT, so the structural predictor received less weight as confidence increased in this fit. This single-seed experiment shows that the gate can operate on the released encoder blocks' outputs under the adapted input format. The held-out metrics provide little evidence of a performance benefit from conditioning the blend on pLDDT.

## Discussion replacement

Interpret the confidence gate by comparing it with the same model using a learned global mixture. The sequence-only and homology-transfer controls establish whether the structural view adds value beyond sequence information on this split. Treat the residue-attention component as conditional on the backbone and fusion regime. The controlled factorial design permits comparison of the confidence prior under fixed and adaptive fusion while holding encoder capacity and the classifier constant. The earlier Struct2GO pattern described in the review, with lower BPO and CCO performance for attention alone, is consistent with a limited or task-dependent contribution from residue-level reweighting. Local model confidence estimates structural reliability. A residue's relevance to a GO label depends on the protein and term. Flexible regions can contribute to functional interactions even when their structural confidence is low. This is a hypothesis for the mixed results and would require residue-level or subgroup evaluation to test directly.

## Reviewer response draft

### Major comment 1. Broader comparisons and backbone validation

We added matched sequence-only, structure-only, and fixed-fusion controls, a compact DeepGOPlus comparison with training-only DIAMOND annotation transfer, and a compact one-hot DeepFRI comparison. We also tested the effect of a confidence-dependent score blend on the released TAWFN encoder blocks adapted to our input representation. The revised Results tables report both the individual models and the paired effects of the confidence components.

### Major comment 2. Plug-in scope

We now distinguish the residue-level attention prior from the post-encoder fusion gate. The former requires residue graph attention. The latter consumes pooled representations or predicted scores and attaches outside message passing. The GCN experiment tests the embedding interface without a GAT layer, and the adapted TAWFN experiment tests the score interface while holding the trained encoders fixed. We restrict the generality claim to these interfaces and evaluated architectures.

### Minor comment 1. Literature coverage

We added work from 2024–2026 on multiscale sequence–structure integration, domain-aware graph modeling, and protein function annotation with sequence and language representations.

### Minor comment 2. Multiple AlphaFold models

We clarified that the dataset archive contains one confidence vector and contact graph per protein. We describe the preprocessing provenance that is documented, identify the missing release and model identifiers, and discuss how variation in contacts and pLDDT could affect the two confidence pathways.

### Minor comment 3. Ablation

We consolidated the comparison into a two-by-two table of ordinary versus confidence-weighted attention under global versus confidence-dependent fusion. We distinguish this controlled experiment from the earlier backbone results, describe mixed effects across conditions, and avoid attributing the observed branch differences to specific residues without direct evidence.
